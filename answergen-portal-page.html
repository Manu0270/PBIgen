What is the Answergen User Portal?

The Answergen User Portal is a white-label portal that serves Power BI reports to unlimited viewers on flat Azure or Fabric capacity, so companies do not pay a per-user Power BI Pro license for every business user. It adds single sign-on, dynamic row-level security and one-click user invitations.

Portal questions.

Licensing, security and hosting in short answers.

How much does each additional viewer cost?

Viewers do not need a per-user Microsoft license. The portal runs on flat Azure or Fabric capacity, so adding viewers does not add per-user Microsoft software fees.

Which single sign-on providers are supported?

Microsoft Entra ID (Azure AD), Okta and Ping.

How does row-level security work?

Dynamic row-level security enforces data access rules so each user only sees the regional or department data they are authorized to see.

Can I brand the portal with my own company identity?

Yes. The portal is white-labeled, with your branding and executive navigation menus.

Where is the portal hosted?

On the customer's existing Azure or Fabric tenant, or fully managed in PBIgen's secure cloud environment.
